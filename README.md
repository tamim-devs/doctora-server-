# Doctora Server

Backend API for Doctora, a healthcare appointment management platform.

## Technologies

- Node.js
- Express.js
- MongoDB
- Better Auth
- JWT Authentication
- Role Based Access Control

## Features

- User authentication
- Doctor management
- Patient management
- Appointment booking
- Appointment status update
- Doctor approval system
- Reviews and ratings
- Admin dashboard statistics
